BEACH BRAIN · LAGOS

Como instalar:
1. Publica TODOS os ficheiros desta pasta num alojamento HTTPS gratuito (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Abre o endereço no iPhone.
3. No Safari: Partilhar → Adicionar ao ecrã principal → Abrir como aplicação web.
4. Abre uma vez com internet para o service worker guardar os ficheiros.
5. Depois funciona offline.

Duelo:
- Um jogador toca em Duelo → Criar partida.
- Diz ao outro o código LAGOS-XXXXXX.
- O outro abre Duelo, escreve o mesmo código e entra.
- Ambos recebem os mesmos 12 puzzles na mesma ordem.
- No fim comparam pontuação e tempo.

Conteúdo:
- 72 puzzles únicos.
- Solo, Co-op, Duelo.
- Dificuldade 1 a 5.
- Funciona offline após a primeira instalação.
